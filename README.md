# 风之符文 · 天鸣城物语

**WIND RUNE · Chronicle of Amane**：第三人称 3D 日式古典奇幻冒险动作 Demo（探索 / 简单战斗 / 环境解谜）。

- 渲染：three.js + 自写卡通着色（二值化光照、描边、边缘光、水彩噪点、植被摆动、空气透视雾、Bloom、调色）
- 美术：全部模型和贴图都在运行时用代码生成，由模块化构件拼装而成（墙 / 门 / 窗 / 屋顶 / 拱门 / 阳台，树 / 石 / 草 / 遗迹）
- 音频：用 WebAudio 实时合成的音乐、环境音和音效，不依赖任何外部文件

---

## 一、如何运行

1. 用 **Chrome 或 Edge（最新版）** 直接**双击 `index.html`**。不需要安装、不需要联网，也不需要本地服务器。
2. 在标题画面点 **「开始新游戏」**，再点击一下画面锁定鼠标。建议全屏游玩：点标题菜单或暂停菜单里的 **「全屏模式」**，或按 **F2**（再按一次退出，也可以按 Esc 退出）。
3. 浏览器需要开启硬件加速（WebGL2）。如果启动失败，页面上会显示原因。

> 如果浏览器限制了本地文件，可以在 `WindRune` 目录下运行 `python -m http.server 8765`，然后访问 `http://localhost:8765`。

## 三、世界与玩法

### 两张可往返的地图，外加一个地下遗迹

| 区域 | 内容 |
|---|---|
| **天鸣城**（古典奇幻城市） | 石板路、中央喷泉广场、集市街、运河与拱桥、风车磨坊、塔楼、风之神殿、城墙与南城门、木梁民居、屋顶、阳台，还有 8 位可交谈的居民 |
| **苍风原野**（城外自然世界） | 草原（随风摆动的草海）、**翠影之森**、**清音川**（河流与浅滩）、山坡、**断风峡**断桥、**风祭遗迹**、**回音洞**、野外神社，以及远处的古塔 |
| **风脉回廊**（神殿地下遗迹） | 符文门厅、推箱压板、风扇浮桥、守卫战、三座风轮，中心是「天鸣之心」 |

- 天鸣城与苍风原野之间以 **南城门** 连接，神殿祭坛与风脉回廊之间以 **阶梯** 连接。切换时有很短的淡入淡出，**玩家状态（生命、位置）和世界进度会完整保留**，可以反复往返。
- 两张地图共用同一套世界坐标：在城外能看到天鸣城的城墙和屋顶轮廓，在城里也能望见城外的山丘和远处的古塔。

### 唯一的核心能力：风之符文

| 用途 | 游戏中的例子 |
|---|---|
| 激活古代机关 | 风之塔柱、符文台座、神殿与地下遗迹的机关 |
| 推动物体 | 把遗迹和地下遗迹里的石块吹到压力石板上；推倒峡谷边的古柱 |
| 转动风车 | 城里的风车和风向标、城门风轮、地下的三座风轮与风扇 |
| 驱散障碍 | 缠住城门风轮的荆棘、笼罩遗迹入口的瘴雾 |
| 击退敌人 | 击退 **埴轮兵**；黑紫色的 **怨灵** 剑打不动，只能用风吹散 |
| 显示隐藏符文 | 被尘土掩盖的压力石板、洞穴里的宝箱符文、地下墙上的顺序提示 |

除此之外只有剑击、闪避、跳跃、冲刺、攀爬这些基础动作，没有别的技能。

**瞄准方式**：风总是朝镜头正前方吹出。只有当某个机关或敌人离准星方向很近（十几度以内）时，才会自动对准它，这时目标上会显示青色的锁定光圈。所以按 F 之前就能看到风会吹向哪里；想吹别的东西，把镜头转过去即可。

### 其他

- 生命以心形显示，受伤后可以拾取掉落的心回复。倒下后会回到最近的检查点，进度不会丢失。
- 屏幕右下角是小地图，屏幕上的菱形标记指向当前目标（可在设置中隐藏）。
- 有 **2 个隐藏的「心之容器」**（生命上限 +1），结局会统计找到的秘密数量。

## 四、流程（剧透）

<details>
<summary>点击展开完整攻略</summary>

**天鸣城**
1. 在中央广场与喷泉旁的巫女 **千风** 交谈。
2. 触碰喷泉北侧的 **风之石碑**，习得风之符文。对石碑两侧的风向标试着吹风。
3. 前往南城门，与守门人 **岩助** 交谈。
4. 用风吹散缠在城门风轮上的荆棘，再对风轮吹几次风，**城门开启**。

**苍风原野**
5. 出城往东南方向走。来到 **断风峡** 的断桥时，用风推倒岸边的古柱，古柱会倒下架成一座桥。
6. 用风吹散 **风祭遗迹** 入口的瘴雾。
7. 唤醒遗迹中的三座 **风之塔柱**：
   - 一座直接吹风就能唤醒；
   - 一座在高台上，要从藤蔓墙爬上去；
   - 一座在石门后面：先用风吹出门旁地面上隐藏的符文，找到压力石板，再把石块吹到石板上，石门就会打开（石块卡住时可以「复位石块」）。
8. 取得祭坛上浮现的 **风之结晶**。

**返回天鸣城**
9. 带着结晶回城。城市机关会产生共鸣：街灯亮起，神殿封印消散。
10. 进入风之神殿，把结晶献于祭坛，**地下入口开启**。

**风脉回廊（约 3～5 分钟的风力机关谜题）**
11. 门上有三个符文凹槽。用风吹墙上的刻痕会显现顺序提示，然后按顺序对三座符文台座吹风（顺序错了会重置）。
12. 把石块吹到压力石板上，铁栅升起，露出风扇。
13. 对风扇吹风，石板会浮起来，趁这时过桥。
14. 进入核心大厅后会出现守卫，全部击败后风轮的封印解除。
15. 让三座风轮 **同时** 转起来。每座风轮被吹动后只会持续转约 25 秒，前方的光环会随剩余时间缩小，再吹一次可以重新计时：
    - 第一座可以直接吹；
    - 第二座在高台上，要沿藤蔓爬上去再吹；
    - 第三座被铁栏挡住，要从旁边的 **通风口** 把风送进去。
16. 三座风轮同时转动时，「天鸣之心」开启。放入风之结晶，**城市核心启动**。
17. 结局：喷泉、塔楼和城外的遗迹、古塔同时恢复运转，**Demo 结束**。结束后可以选择「继续探索」，在金色午后的世界里自由活动。

**隐藏的心之容器**
- 城里旧粮仓的屋顶：从西侧的藤蔓墙爬上去。
- 回音洞深处：用风吹洞里的后墙。

</details>

## 五、画质与性能

- 设置里可以选择 **低 / 中 / 高** 画质。首次运行时会根据显卡自动选一档；游戏开始后如果帧率不够，会自动降一档并给出提示。手动选过画质之后就不再自动调整。
- 低画质会降低渲染分辨率、关闭抗锯齿、降低阴影精度，并减少草的密度和可见距离，适合集成显卡或笔记本。
- 其他设置：全屏、鼠标灵敏度、反转 Y 轴、音乐和音效音量、目标标记、帧率显示。
- 鼠标使用原始输入（不受系统"提高指针精确度"加速影响），手感偏慢或偏快时请调整「鼠标灵敏度」。

## 六、存档

- 进入新区域、完成关键进度以及回到标题时会 **自动存档**，存档保存在浏览器的 localStorage 里。
- 在标题画面点「继续游戏」读取存档。点「开始新游戏」会覆盖旧存档。
- 存档跟着浏览器走：换一个浏览器，或者清除了网站数据，存档就会消失。

## 七、项目结构

```
WindRune/
├─ index.html        页面、全部 UI（HUD、菜单、对话框、结局）与样式
├─ game.js           打包后的游戏（由 src/ 构建，直接被 index.html 引用）
├─ build.mjs         esbuild 构建脚本
├─ package.json
├─ tools/
│  └─ collision-audit.js  开发工具：在浏览器控制台运行，列出"看得见却没有碰撞体"的位置（用法见文件开头）
└─ src/
   ├─ main.js        启动、加载进度、着色器预热、主循环
   ├─ core/          引擎（渲染管线 / 画质档位）、输入、音频合成、工具函数
   ├─ gfx/           卡通材质与着色器补丁、程序化贴图、天空、水面、后期与特效
   ├─ game/          游戏主控、玩家、相机、风之符文、物理碰撞、敌人、NPC、
   │                 可交互机关（entities）、角色模型与动画（avatar）、任务、存档
   ├─ ui/            HUD / 小地图、对话与获得物品、菜单
   └─ world/         模块化构件库（kit）、几何合并（geom）、植被与草地（nature）、
                     道具（props）、区域基类（zone）、共享地形（shared）、
                     天鸣城（city）、苍风原野（wilds）、风脉回廊（undercroft）
```

### 修改后重新构建

需要 Node.js 18 或更高版本：

```bash
npm install
node build.mjs            # 生成 game.js
node build.mjs --watch    # 开发时保存后自动重建
node build.mjs --minify   # 生成压缩版
```

## 八、已知限制

- 只支持键盘和鼠标，暂不支持手柄和触屏。
- 需要支持 WebGL2 的浏览器，推荐 Chrome / Edge。没有在 Safari 上测试过。
- 点击画面锁定鼠标时，浏览器会弹出「按 Esc 显示光标」之类的提示，这是浏览器自己的行为。
- 所有模型、贴图和音乐都是程序生成的，风格统一，但细节比不上手工制作的美术资源。
- 全屏使用浏览器的全屏 API：在普通 Chrome / Edge 中可用；嵌在其他应用里的网页视图可能不允许全屏（按钮会自动隐藏，或点击后没有反应）。

## 九、更新记录

**碰撞、转向、瞄准与全屏（本次更新）**
- **修复穿模**：用碰撞审计工具（`tools/collision-audit.js`）逐个检查了三张地图里所有可见模型在身体高度上是否有碰撞体覆盖，然后补齐或修正了碰撞：
  - 城外的灌木、岩石、洞穴岩壁、树干都改为按模型实际形状生成碰撞（斜坡上也按当地地面计算）；树枝和树冠抬到头顶以上，斜坡上树冠会垂到头部高度的位置不再种树。
  - 补上了集市摊位后排立柱、推车把手、长椅靠背、路牌、稻草人、农田作物、草垛、雕像、宝箱、洞里的水晶和蘑菇、遗迹倒地断柱和平台石沿、柱础、地下遗迹的风轮支架与转盘、风道管、风扇罩、火盆、城门立杆、房屋门前台阶的碰撞；断柱的碰撞高度改为断裂后的实际高度，不再有空气墙。
  - 修正了遗迹高台顶和粮仓屋顶"脚陷进石板"的问题；花坛、摊位、NPC 头顶不再能站人。
  - 堵住了从运河游泳穿过城墙水门出城的漏洞；运河墙和桥拱在水下也有碰撞。
  - 不可站立的物体从上方落下时会把角色推开，而不是让角色陷进去；贴着陡坡或悬崖时，身体前缘也会检测地形，不再陷进崖壁。
  - 敌人（埴轮兵）和小葵等 NPC 不能再被穿过；相机不会再钻进运转中的喷泉水幕。
- **转向更平滑**：身体朝向改为限速平滑转动（停步时转得快，奔跑、冲刺时更稳），攻击、施放、翻滚、对话等瞬间转向也会用约 0.15 秒转过去；移动方向仍立即响应按键，窄桥、平台上的操作不受影响。鼠标输入过滤了指针锁定下偶发的"视角突然猛转"。
- **风的方向不再偏移**：修复了自动瞄准会错误地吹向其他石台或敌人的 bug（多个目标共用了同一个坐标对象）；自动瞄准的范围从 ±43° 收窄到十几度，并新增青色锁定光圈；出手瞬间按当前镜头方向重新瞄准，风从手部发出并汇聚到瞄准点。
- **新增全屏**：标题 / 暂停菜单的「全屏模式」、设置里的「全屏」开关、F2 快捷键。
- 其他：读档后已击败的敌人不会再复活；启动时不再冒出地下遗迹的提示；启动时预编译全部着色器，减少首次进入区域时的卡顿。
